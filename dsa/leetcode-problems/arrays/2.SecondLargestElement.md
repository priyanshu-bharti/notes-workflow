type: "DSA"
topic: "Arrays"
problem: "Find the Second Largest Element"
difficulty: "Easy"
description: "Given a list of integers, return the second largest unique element. If no such element exists (i.e., all elements are the same), return -1."
use-cases: "Used in ranking problems, leaderboard systems, and any scenarios where relative ordering of unique values is important."
time-complexity: "O(n) — where n is the number of elements in the list, as we iterate through the list once."
space-complexity: "O(1) — only constant extra space is used for tracking the max and second max values."
naive-approach: "Sort the list and iterate from the end to find the second unique largest element. This approach has a time complexity of O(n log n). We can also do this in 2 loops by finding the max in one loop, and then ignoring the max value and again finding the max (which'll give us 2nd max.)"
optimal-approach: "Traverse the list once while maintaining two variables — one for the maximum and one for the second maximum — and update them as needed."
---

```py
import math

def secondLargestElement(nums):
    # Initialize both the maximum and second maximum to negative infinity.
    # This ensures any number in the list will be greater during comparison.
    second_max = maximum = -math.inf

    # Calculate the size of the input list
    size = len(nums)

    # If the list has fewer than 2 elements, there's no valid second largest value
    if size < 2:
        return None

    # Iterate over each number in the list
    for i in range(size):
        curr_value = nums[i]

        # Case 1: Current number is greater than the current maximum.
        # - We update second_max to be the old maximum.
        # - We update maximum to be the new number.
        # This ensures the second_max is always the second best seen so far.
        if curr_value > maximum:
            second_max = maximum
            maximum = curr_value

        # Case 2: Current number is less than the current maximum,
        # but greater than the current second maximum.
        # - This means it's a potential candidate for second largest.
        # - We must also ensure it's not equal to the maximum to avoid duplicates.
        elif curr_value > second_max and curr_value != maximum:
            second_max = curr_value

    # After the loop, if second_max is still -inf, it means no valid second largest number was found.
    # This could happen if all values are the same or only one unique value exists.
    return second_max if second_max != -math.inf else -1

# Test cases
nums = [[8, 8, 7, 6, 5], [10, 10, 10, 10, 10]]

for num in nums:
    result = secondLargestElement(num)
    print(result)

```
