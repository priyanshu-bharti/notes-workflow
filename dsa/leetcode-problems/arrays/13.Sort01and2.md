description: "Given an array with 0s, 1s, and 2s (representing red, white, blue), sort them in-place so that the same colors are adjacent and in the order red → white → blue."
use-cases: "Used in problems involving 3-way partitioning or categorization without extra space."
time-complexity: "O(n)"
space-complexity: "O(1)"
naive-approach: "Use any sorting algorithm like quicksort or merge-sort (O(n log n)). Avoid this as it's unnecessary for only 3 distinct values."
optimal-approach: "Use 3 pointers (lo, mid, hi). Move 0s to the front, 2s to the end, and leave 1s in the middle using swaps. This is known as the Dutch National Flag algorithm. After swapping with hi (2s), don't increment mid pointer because the new value at mid might be 0 or 2 and needs re-checking."

```py
"""
Given an array nums with n objects colored red, white, or blue, sort them
in-place so that objects of the same color are adjacent, with the colors in the
order red, white, and blue.

We will use the integers 0, 1, and 2 to represent the color red, white, and
blue, respectively.

You must solve this problem without using the library's sort function.

Example 1:
----------
Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]

Example 2:
----------
Input: nums = [2,0,1]
Output: [0,1,2]
"""

from typing import List


def sortColors(self, nums: List[int]) -> None:
    """
    Sorts the input list in-place such that all 0s (red), 1s (white), and 2s (blue)
    are grouped together in the order: red -> white -> blue.

    Uses the Dutch National Flag algorithm for 3-way partitioning:
    - All 0s to the left
    - All 2s to the right
    - All 1s naturally fall in the middle

    This avoids the use of any sorting library and operates in O(n) time and O(1) space.
    """

    # Just for readability
    size = len(nums)

    # Pointer `lo` keeps track of the boundary for the region of 0s (red).
    # All elements before `lo` are guaranteed to be 0.
    lo = 0
    # Pointer `hi` keeps track of the boundary for the region of 2s (blue).
    # All elements after `hi` are guaranteed to be 2.
    hi = size - 1

    # `i` walks the list left to right. Items between `lo` and `i` are unsorted.
    i = 0

    # Walk the list until we've reached hi (since everything after it is already sorted.)
    while i <= hi:
        # Get the current item.
        curr = nums[i]

        # Found a red (0). Place it in the left (red) region.
        # Swap with the value at `lo`, which could be 0, 1, or 2.
        if curr == 0:
            # Swap the items
            nums[i], nums[lo] = nums[lo], nums[i]
            # Move the lo and i pointer ahead, as 0 has been placed to the right spot.
            lo += 1
            i += 1

        # Found a blue (2). Place it in the right (blue) region.
        # Swap with the value at `hi`, which could be 0, 1, or 2.
        elif curr == 2:
            # Swap the items
            nums[i], nums[hi] = nums[hi], nums[i]
            # Move the hi pointer behind
            hi -= 1
            # Important: DO NOT MOVE i as it might be a 0 or 2 after swap.

        # Found a white (1). It's already in the correct middle region.
        # Just move to the next element.
        else:
            i += 1


inputs = [
    [2, 0, 1],
    [2, 0, 2, 1, 1, 0],
]

for ip in inputs:
    print("Before Sorting :", ip)
    sortColors(None, ip)
    print("After Sorting :", ip)

```
