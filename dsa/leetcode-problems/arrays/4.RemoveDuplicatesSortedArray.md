```py
"""
Given an integer array nums sorted in non-decreasing order, remove the duplicates
in-place such that each unique element appears only once. The relative order of
the elements should be kept the same. Then return the number of unique elements in nums.

Consider the number of unique elements of nums to be k, to get accepted, you
need to do the following things:
    1. Change the array nums such that the first k elements of nums contain the
    unique elements in the order they were present in nums initially.
    2. The remaining elements of nums are not important as well as the size of nums.
    3. Return k.

Example 1:
----------
Input: nums = [1,1,2]
Output: 2, nums = [1,2,_]
Explanation: Your function should return k = 2, with the first two elements of
nums being 1 and 2 respectively. It does not matter what you leave beyond the
returned k (hence they are underscores).

Example 2:
----------
Input: nums = [0,0,1,1,1,2,2,3,3,4]
Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]
Explanation: Your function should return k = 5, with the first five elements of
nums being 0, 1, 2, 3, and 4 respectively.  It does not matter what you leave
beyond the returned k (hence they are underscores).
"""

from typing import List

"""
Approach & Intuition:
---------------------
Since the array is sorted, duplicate values will always be **adjacent**.

We use the **two-pointer technique**:
    - One pointer `unique` tracks the position of the last placed unique element.
    - The second pointer `curr` scans through the array from left to right.

Key Idea:
---------
When we see a new unique element (i.e., nums[curr] != nums[unique]):
    - Increment `unique` to make space for the new unique element.
    - Copy nums[curr] to nums[unique] — placing the unique element in the right spot.

We do this in-place, with no extra space, and only one pass through the array.
"""


def removeDuplicates(self, nums: List[int]) -> int:
    # Get the size of the array
    size = len(nums)

    # If there's 0 or 1 element, it's already unique — return its length
    if size <= 1:
        return 1

    # Initialize pointer for the last unique item in the list.
    unique = 0

    # Walk over each item in the array.
    for curr in range(1, size):
        # If curr item is not same as the unique item, we have a unique item.
        if nums[curr] != nums[unique]:
            # Move the pointer ahead.
            unique += 1
            # Copy the value
            nums[unique] = nums[curr]

    # Return the number of unique items
    return unique + 1


inputs = [
    [1, 1, 2, 2, 3, 5, 5, 6, 7, 8],
    [1, 1, 2],
    [0, 0, 1, 1, 1, 2, 2, 3, 3, 4],
    [1],
]


for ip in inputs:
    result = removeDuplicates(None, ip)
    print(result)

```
